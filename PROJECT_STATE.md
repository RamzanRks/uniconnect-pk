# UniConnect PK — Project State (Handoff Document)

## Overview
Full-stack student collaboration platform for Pakistani universities.
Strict .edu registration, project partner board, Q&A, applications,
reporting/moderation, admin panel, verification badges.

## Stack
Backend: Node/Express/Mongoose/JWT/Multer/Socket.io | DB: MongoDB Atlas
Frontend: React(Vite)+Tailwind+Axios+React Router+socket.io-client
